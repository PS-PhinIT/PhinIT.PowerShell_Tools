# Code of Conduct / Verhaltenskodex

## Unser Versprechen

Die Mitarbeit an diesem Projekt soll für alle eine belästigungsfreie Erfahrung sein – unabhängig von Alter, Körpergröße, Behinderung, ethnischer Zugehörigkeit, Geschlechtsidentität und -ausdruck, Erfahrungsstand, Nationalität, Aussehen, Religion oder sexueller Orientierung.

## Erwartetes Verhalten

- Respektvoll und konstruktiv bleiben.
- Feedback annehmen und sich auf das Beste für das Projekt konzentrieren.
- Empathie gegenüber anderen Mitwirkenden zeigen.

## Inakzeptables Verhalten

- Belästigung, Beleidigungen oder diskriminierende Kommentare.
- Veröffentlichung privater Informationen anderer ohne deren Erlaubnis.
- Jedes andere Verhalten, das in einem professionellen Umfeld unangemessen wäre.

## Durchsetzung

Die Maintainer dürfen Kommentare, Commits, Code, Issues und andere Beiträge entfernen, bearbeiten oder ablehnen, die diesem Verhaltenskodex nicht entsprechen. Vorfälle bitte über ein GitHub-Issue oder per privater Nachricht an die Maintainer melden.

Dieser Verhaltenskodex basiert auf dem [Contributor Covenant](https://www.contributor-covenant.org/), Version 2.1.
